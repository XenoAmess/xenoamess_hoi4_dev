钢奶龙心 1.0 — HOI4 1.20 更新

让圆滚滚的奶龙陪大家享受策略游戏；反对种族歧视，尊重不同国籍和族群的玩家，珍惜现实中的和平。

• 适配本机已核验的 HOI4 1.20.0 / Build 26733403；人物贴图逐项采用各自原版来源的尺寸。
• 本包包含 5,815 个贴图绑定，较上一公开包净增 236：新增 286 个路径、更新 8 个既有贴图路径、移除 50 个旧路径。
• 按 DLC 路径优先级实际选用 5,633 个人物来源及 5 个非人物原图例外；BACK SOON 门牌保留原字节，不计 AI 人物完成。
• 已安装库存 5,888 个唯一来源中，5,883 个人物来源已完成美术审查，另有上述 5 个原图例外；上版清点发现的 3 个人物素材缺口已补齐。
• 中国共产党及相关势力的替换素材仅供归档，不随本安装包分发；实际 staging／ZIP／来源清单已额外审计，禁入命中 0。范围不扩展到外国共产党势力。
• 1.20 实机抽查覆盖七国选国主卡、罗马尼亚 Gheorghe Tătărescu 与菲律宾 Manuel Quezon 信息头像。其他人物、顾问、事件和 DLC 组合未作逐项实机遍历，440 条未解析引用仍独立记录。
• 高清原始 PNG、返修历史和完整请求继续保存在普通 Git 中；安装包仅含游戏 payload。

Hearts of Nailong 1.0 — HOI4 1.20 update

A small wish for peace: oppose racial discrimination, respect players of every nationality and background, and keep fictional conflicts separate from real people.

• Targets the locally verified HOI4 1.20.0 / Build 26733403. Each game texture retains its own original source dimensions.
• 5,815 texture bindings, 236 more than the previous public package: 286 paths added, 8 existing texture paths updated and 50 old paths removed.
• The package selects 5,633 distinct character sources and five byte-preserved non-person sources using DLC path precedence. The BACK SOON door is an original-image exception, not AI character credit.
• The installed inventory has 5,888 unique sources: 5,883 art-approved characters and five preserved originals. The three character-art gaps found during the prior release inventory are now filled.
• Chinese CCP-related replacement assets are archive-only and excluded from the install payload. A fresh actual staging/ZIP/source audit found zero prohibited payload matches; foreign communist factions are not excluded as a class.
• Limited live checks on 1.20 cover seven major-country cards plus Romania/Gheorghe Tătărescu and Philippines/Manuel Quezon. Other characters, advisors, events and DLC combinations are not individually certified; 440 unresolved references remain documented.
• Original HD PNGs, revision history and full requests remain unchanged in ordinary Git. Only the game payload enters the install package.

安装：将 `gangnailongxin.zip` 解压至 HOI4 的 mod 目录并配置外层 `.mod`，或订阅 [Steam 创意工坊原条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3830400579)。

本说明随发布准备冻结；两平台实际结果以 publication/1.0-update-20261125 后续回执为准，保留此前 Release 和媒体附件。
