# 钢奶龙心 1.0

首次公开发布版本。逐来源制作人物奶龙头像，保留服装、毛发、配饰、姿态与取景；游戏贴图对齐各自原版来源分辨率，高清生成 PNG 原始字节另行完整归档。

- 5317 个贴图绑定，含 4 个已登记非人物原图例外。
- 已知独立来源完成 5239/5485（95.52%）；其余 246 个已知来源和历史未解析引用继续公开记录。
- HOI4 1.19.3.0 实测法国、英国和美国的领袖及顾问界面，法国推进到 1936-01-04；未宣称全部界面或 DLC 组合均已实机遍历。
- 加入封面、真实游戏截图和中英双语介绍。

First public version. Individually generated Nailong portraits retain clothing, hair, accessories and poses. Game textures match their own original source dimensions; unchanged HD PNG masters are archived separately.

5317 texture bindings; 5239/5485 known unique sources completed, including four documented non-person exceptions. 246 known sources and historical unresolved references remain. Tested sample screens in France, the UK and USA on HOI4 1.19.3.0; exhaustive gameplay coverage is not claimed.
