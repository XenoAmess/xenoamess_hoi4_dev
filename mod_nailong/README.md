# 钢奶龙心 / Hearts of Nailong

把《钢铁雄心 IV》的人物本体替换为圆滚滚的黄色奶龙，保留每个人原有的服装、发型、胡须、配饰、姿态与取景。

当前公开版本 **1.0**，适配 HOI4 **1.19.x**。GitHub与原创意工坊已于北京时间2026-11-07更新，均包含 **5579 个贴图绑定**，比上一安装包增加262个。1.19.3库存的5481张人物素材均已完成，[最后12张接收记录](data/high12-owner-intake-20261105.json)保存来源、原始 PNG、请求与审图资格核对。该次发布前重新清点本机已安装的1.19.4.1游戏，发现此前库存之外的3个人物来源；当时为 **5481/5484** 人物素材通过，另有4个非人物例外保留原图。此清点不证明这3个来源何时加入游戏。该次完整正式构建仍有748条既有未解析引用待处理。

本机现为 **1.20.0.0 / Build 26733403**。本次15个新出现的原始SHA（4张大头像、11张小卡）已逐张生成及审查通过，实际待处理图片0；高清原件、返修前后版本与完整请求均保留。当前库存5,888个唯一来源包含5个非人物原图例外，440条未解析引用继续单列；1.20完整原尺寸包及实际发布排除审计已通过并完成本地部署；已实际抽查七国主卡、罗马尼亚新Tatarescu及菲律宾Quezon选国头像并正常退出，见[有限实机回执](data/update-plans/20261121-limited-live-qa.json)，见[本轮计划](docs/hoi4-1.20.0-portrait-plan.md)。

此前1.19.5新增395个来源的处理仍保留为历史完成结果：394个AI头像通过、1个BACK SOON原图例外，三个更早人物缺口亦已补齐。其5,810贴图工作构建的原尺寸与实包排除审计通过，但仅完成1.19.5主菜单启动及正常退出，不能代替1.20头像实机；见[旧构建回执](data/update-plans/20261119-full-native-build.json)及[旧任务表](docs/hoi4-1.19.5-portrait-plan.md)。当前工作库存尚未替换下方的旧公开安装包。

游戏贴图逐项采用其原版来源的分辨率。完整高清生成 PNG 原件按原始字节保存在 [`assets/generated_fullsize/`](assets/generated_fullsize/)，用于素材追溯；其中也包含历史版本和未通过审图的结果，不能把素材归档数量当作当前合格数量。[高清索引](data/fullsize-files.json)记录 SHA、尺寸和来源关联。

请将游戏与现实区分开来，尊重不同国籍、族群与背景的玩家，反对歧视，珍惜和平。完整中英双语介绍见 [Workshop 文案](docs/workshop-description.bbcode)。

从 GitHub Release 下载 `gangnailongxin.zip`，解压到 HOI4 用户目录的 `mod` 下，并创建外层 `.mod` 文件指向该目录；也可在创意工坊订阅。与替换相同头像的其他模组可能冲突，建议先单独启用。

开发工具、完整提示词与审图记录保存在仓库中；只有构建器生成的 staging 内容进入游戏包。内部 manifest 如实保存当前覆盖和验收状态。

生产、重试、纯 OCR/键鼠与素材归档规则见 [AGENTS.md](AGENTS.md)。
