# 小卡片外观辨认

65×67 顾问卡中的上唇阴影、眼睑和白色肩带容易被误认成胡须、眼镜或衬衫。先看原始像素；存在同构图的大原图时，再实际核对头部朝向、发型、服装和配饰。文件名只用于寻找候选，不证明大图与小卡片属于同一外观版本。例如同人物同时有早期闭领军装和后期敞领礼服时，必须按小卡片实际构图选择，不能把另一版的发色或胡须移植过去。

这一复查已澄清若干未调用草稿：圆框眼镜与干净上唇应分别保留；深色闭领军装上的白色斜带不能写成西装衬衫；原图无眼镜时不能把眼部阴影写成镜框。逐项来源 SHA、观察时间、机器身份及哪些实际请求保持原样，见[复查记录](../data/source-feature-clarifications.json)。这些属于分析依据，真正发送的输入仍以每次冻结的 request journal 和实际 payload 校验为准。

已实际派发的请求不改写。未调用草稿需要纠正时，保留原 prompt 和取消原因，再冻结新 attempt；图片已经返回且存在真实美术错误时，按实际图片另作返修。被服务拒绝的请求继续执行原词、原输入、至少八小时与单次重试规则，不能借外观复查换词或换图。

大图只帮助辨认，不能代替小卡片的独立生成、当前输出审图或领口资格，也不改变库存和原始 SHA 去重口径。原版像素与对照工作页保存在本机 runtime，不上传完整游戏素材。
