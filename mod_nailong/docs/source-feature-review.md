# 小卡片外观辨认

65×67 顾问卡中的上唇阴影、眼睑和白色肩带容易被误认成胡须、眼镜或衬衫。先看原始像素；存在同构图的大原图时，再实际核对头部朝向、发型、服装和配饰。文件名只用于寻找候选，不证明大图与小卡片属于同一外观版本。例如同人物同时有早期闭领军装和后期敞领礼服时，必须按小卡片实际构图选择，不能把另一版的发色或胡须移植过去。

这一复查已澄清若干未调用草稿：圆框眼镜与干净上唇应分别保留；深色闭领军装上的白色斜带不能写成西装衬衫；原图无眼镜时不能把眼部阴影写成镜框。逐项来源 SHA、观察时间、机器身份及哪些实际请求保持原样，见[复查记录](../data/source-feature-clarifications.json)。这些属于分析依据，真正发送的输入仍以每次冻结的 request journal 和实际 payload 校验为准。

已实际派发的请求不改写。未调用草稿需要纠正时，保留原 prompt 和取消原因，再冻结新 attempt；图片已经返回且存在真实美术错误时，按实际图片另作返修。被服务拒绝的请求继续执行原词、原输入、至少八小时与单次重试规则，不能借外观复查换词或换图。

大图只帮助辨认，不能代替小卡片的独立生成、当前输出审图或领口资格，也不改变库存和原始 SHA 去重口径。原版像素与对照工作页保存在本机 runtime，不上传完整游戏素材。

2026-10-18 的持续生产中，对 important-021 既有合格图追加了原图细节复查：确认 9 张存在误增胡须、漏眼镜/胡须或敞领服装被闭合的问题，已撤销对应当前图片的资格，并冻结逐张返修词，排入 important-025 开头。不能把旧审图通过当作细节正确的永久证明，也不能因返修让错误版本继续计入合格进度。逐图缺陷与原图身份见[本轮细节复查](../data/source-feature-recheck-021.json)；实际返修结果继续以各来源 generation request journal、当前输出 SHA 和新审图为准，排队不代表返修完成。

同轮复查还确认胡宗南的小卡片与同名大头像眼镜外观不一致，因此保留小卡片自己的可见眼镜，没有照同名大图强行删除。亨利·吉罗的小卡片为无帽版本，菲利普·勒克莱尔的小卡片为头盔版本，后续提示词保留这些差异，不借用同名大图的军帽。新队列同时含小卡片和完整人物像时，分别冻结边框/纸条与无边框背景约束。

对 important-022 的同样复查确认另有 4 张遗漏原图的小胡子或细框眼镜。这些并非应当全部剃净的部位：保留毛发版同时要求无胡须处不增毛、有胡须处不漏毛。对应资格已撤销，逐张原图约束和返修 attempt 见[第二轮细节复查](../data/source-feature-recheck-022.json)，返修排在 important-026 开头。important-021 的 9 张返修图已经实际返回并逐图复查，当前新图的合格状态仍由 journal 和 SHA 绑定的审图决定记录。

important-020 中两张绑定具名人物的亚洲通用小卡片也确认误增胡须，逐图缺陷与排在 important-027 开头的返修记录见[通用卡片复查](../data/source-feature-recheck-020.json)。候选查找不能简单跳过所有 `generic` 文件：国家/区域、`land` 等类别及完整数字编号相同的大小图可列为候选，仍须实际对照服装、姿势和配饰。`land_1` 不能用 `land_10`、另一个国家的 `land_1` 或同区域带 `small` 的另一服装版本代替；不改变原始 SHA 的去重规则。

返修结果也须重查。important-022 的一次返修仍只画了奶龙参考图本来的灰色嘴部，没有在其上方增加原人物的小胡子；另一张虽补回胡子，却在纸条上发明了可读编号，并将原领章的三颗星改成大圆扣。这两张继续退出合格集，按实际返回图另作针对性返修，记录追加在第二轮细节复查中，旧请求和原结果均保留。基础提示词已明确：灰色嘴部及其阴影不算胡须，真实胡须须是嘴部上方独立可见的毛发；原图不可读的纸条不能自行补出编号，领章保留可见符号数量和排列。只有未调用草稿才可取消后重新冻结，实际拒绝仍按原请求冷却重试。
