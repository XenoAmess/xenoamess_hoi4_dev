# Fine lip-detail preparation

Local production review on machine `bf-202609141645-5434332d4d`, 2026-10-20 UTC, found overly broad returned moustaches on several small sources whose actual full prompts already asked for only tiny pale lip detail. The preparation helper also classified the words “clean chin” as a definite moustache-only instruction. Consequently a deliberately cautious source observation could receive a stronger moustache preamble at both ends. This routing is documented as a possible contributing instruction conflict; it does not prove a unique cause for any model output.

New preparation uses `facial_hair_instruction` from `tools/generation_requests.py`. A source note containing “Retain only” and describing lip detail/appearance receives an explicit restraint rule before the moustache-only branch, including when that caution appears in a later sentence. It preserves actual tiny visible detail and any definite fine source hair, without treating a skin shadow or lip highlight as evidence of a hair band. Clear clean-shaven, moustache-only and full-beard descriptions retain their distinct instructions. Regression tests cover these actual production phrasing cases.

This affects newly prepared requests only. Previously frozen prompts, actual JS snapshots, tool flags, reference order/bytes and service refusals remain unchanged. Any future result still requires actual source/raw review; this change is not a quality-improvement claim. Source images remain the authority when a previous feature note proves overstated, as recorded for source 131/27 in `data/native-source-recheck-131-2026-10-20.json`.
