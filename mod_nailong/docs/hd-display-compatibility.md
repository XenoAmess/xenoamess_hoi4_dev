# 高清纹理与界面显示尺寸

2026-10-18 用户要求游戏默认使用生成工具返回的高清原图；只有确认必须缩放才能避免问题时，才允许个别缩放例外。当前 builder 从原始高清 PNG 编码无损 RGBA DDS，保留全部像素，审图缩略图不再作为游戏输入。

本机 `machine_id: bf-202609141645-5434332d4d` 的实测使用 HOI4 Operation Postern v1.19.3.0.c01a (5632) (S)，EXE SHA-256 `7dc947be34970da1e1c787bcddbe7f62b610ff258aebf8f06aa8b348f3a031d5`。具体 UTC、原始截图 SHA、构建和来源见 [逐次实测记录](../data/hd-logical-display-probes-2026-10-18.json) 与 [直接高清替换记录](../data/hd-native-texture-probe-2026-10-18.json)。这些记录只证明该机器、该版本、罗斯福单人物夹具的对应显示位置。

| 方案 | 实测结果 |
| --- | --- |
| A：直接用 1081×1455 高清 DDS 替换原 156×210 文件 | 能加载，但选国卡头像按纹理像素放大，遮住界面。不能直接视为兼容。 |
| B：普通 `spriteType` 添加 `size` | 实际解析日志拒绝此属性。不能继续作为解决方案。 |
| C：`corneredTileSpriteType`，逻辑尺寸 156×210、零边框、不平铺，纹理仍为 1081×1455 | 主选国卡和进入美国后的政治领袖相框正常；下方选国详情与地图开局侧栏忽略原 icon 的缩放，仍有溢出。整体未通过。 |
| D：保留 C 的高清纹理，实验性把两个前端头像控件改为按钮类型 | 实测失败：选择美国后，下方头像退回原始未知人物剪影，未绑定到罗斯福。不能作为适配方案；生成的原版 GUI 副本只在忽略的开发 staging 内。 |
| E：保留图标控件，实验性添加显式尺寸约束 | 准备测试，尚无通过结论。 |

显示尺寸适配不等于提前降低纹理分辨率。C 的局部成功证明至少部分位置可以使用高清纹理；其余位置仍须逐类实测。当前没有批准任何降采样例外，也没有声明全部高清显示兼容。正式发布仍需完整美术覆盖、引用解析及实机资格。
