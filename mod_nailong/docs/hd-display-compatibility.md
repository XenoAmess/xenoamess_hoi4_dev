# 高清纹理与界面显示尺寸

2026-10-18 用户要求游戏默认使用生成工具返回的高清原图；只有确认必须缩放才能避免问题时，才允许个别缩放例外。当前 builder 从原始高清 PNG 编码无损 RGBA DDS，保留全部像素，审图缩略图不再作为游戏输入。

本机 `machine_id: bf-202609141645-5434332d4d` 的实测使用 HOI4 Operation Postern v1.19.3.0.c01a (5632) (S)，EXE SHA-256 `7dc947be34970da1e1c787bcddbe7f62b610ff258aebf8f06aa8b348f3a031d5`。具体 UTC、原始截图 SHA、构建和来源见 [逐次实测记录](../data/hd-logical-display-probes-2026-10-18.json) 与 [直接高清替换记录](../data/hd-native-texture-probe-2026-10-18.json)。这些记录只证明该机器、该版本、罗斯福单人物夹具的对应显示位置。

显示尺寸适配不等于提前降低纹理分辨率。C 的局部成功证明至少部分位置可以使用高清纹理；其余位置仍须逐类实测，并验证点击区域、动态绑定、工具提示与布局。当前没有批准任何降采样例外，也没有声明全部高清显示兼容。正式 builder 的高清显示资格门禁保持未通过，不能因为美术覆盖达到全量就发布已知界面异常的包。

M 的精确构建/母版 SHA、实际截图时间和本机身份另见 [初始化类型实验](../data/hd-placeholder-initializer-probe-2026-10-19.json)。已正常关闭游戏，保持 Steam 离线并恢复实验前的开发预览，回执在 [M 实验恢复记录](../data/hd-initializer-probe-restoration-2026-10-19.json)。该实验失败没有批准任何缩图例外。

审图页与游戏纹理分别处理。`review_pairs.py` 新建的 v2 审图页直接读取校验过 SHA 的原始高清母版，保持长宽比后适配展示框，不再先把旧 65×67 派生预览拉伸放大。页面上的缩略展示不改母版或游戏 DDS；审图决定同时绑定母版 SHA、生成 attempt 与既有预览 SHA，避免相同预览对应的母版变化后沿用旧批准。历史审图证据保留原样，不追认为已经看过高清母版。
