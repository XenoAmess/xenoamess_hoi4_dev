# 高清纹理与界面显示尺寸

2026-10-18 用户要求游戏默认使用生成工具返回的高清原图；只有确认必须缩放才能避免问题时，才允许个别缩放例外。当前 builder 从原始高清 PNG 编码无损 RGBA DDS，保留全部像素，审图缩略图不再作为游戏输入。

显示尺寸适配不等于提前降低纹理分辨率。C 的局部成功证明至少部分位置可以使用高清纹理；其余位置仍须逐类实测，并验证点击区域、动态绑定、工具提示与布局。当前没有批准任何降采样例外，也没有声明全部高清显示兼容。正式 builder 的高清显示资格门禁保持未通过，不能因为美术覆盖达到全量就发布已知界面异常的包。
